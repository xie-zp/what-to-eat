# LangChain 学习路线

项目代码暂时不继续扩展，先按下面的顺序学习。

## 课程

1. `01_plain_openai.py`：不用 LangChain，直接调用 OpenAI 兼容 API
2. `02_langchain_chat_model.py`：使用 LangChain 的 ChatOpenAI
3. `03_messages_and_prompts.py`：消息和提示词模板
4. `04_structured_output.py`：Pydantic 结构化输出
5. `05_tool_calling.py`：工具定义和 Tool Calling
6. `06_retriever_rag.py`：Document、Embedding 和 Retriever
7. `07_langgraph_loop.py`：LangGraph 状态图

每一课只讲一个概念，并能独立运行。
