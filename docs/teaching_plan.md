# 项目讲解计划

项目完成后统一讲解，讲解顺序固定为四层：

1. 一句话说明这个模块解决什么问题
2. 用生活化流程说明数据如何流动
3. 对应到项目文件和代码
4. 整理面试官可能追问的问题

## 讲解原则

- 不先讲框架名词
- 不一次讲多个概念
- 每个模块先讲输入和输出
- 先讲普通 Python 实现，再说明框架解决了什么问题
- 每个设计都回答“为什么需要它”

## 最终讲解材料

- `docs/architecture.md`：真实系统架构
- `docs/project_story.md`：三分钟项目介绍
- `docs/interview_guide.md`：面试问题和回答
- `docs/evaluation.md`：测试与评测结果
