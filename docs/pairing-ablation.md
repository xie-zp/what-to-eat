# 搭配类问答消融实验

针对"鸡肉配什么蔬菜"这类关系型问题，对比四种方案的搭配准确率。

## 实验设计

- **查询集**：8 个主食材（鸡肉、牛肉、猪肉、豆腐、虾、鸡蛋、羊肉、鱼）× "配什么蔬菜"
- **标准答案**：独立计算——先扫出含该主食材（含别名）的全部菜谱，再收集这些菜谱里的蔬菜类食材
- **指标**：Precision@8（返回前 8 个搭配中，真实共现过的比例）
- **两个基线模拟传统 RAG**：先检索菜谱，再从菜谱食材里筛出蔬菜
- **复现**：`python scripts/evaluate_pairing.py`

## 实验结果

| 方案 | Precision@8 | 平均延迟 |
|---|---:|---:|
| 纯向量检索 + 食材提取 | 0.867 | 325 ms |
| 纯 BM25 检索 + 食材提取 | 0.964 | 2 ms |
| 图谱共现统计 | **1.000** | 9 ms |
| 图谱多跳路径 | 0.875 | 72 ms |

## 结论

1. **图谱共现统计效果最好（1.000）**，但要注意：它与标准答案同源（都由菜谱数据的共现关系推导），接近满分属于结构性结果，不能独立证明方案优越。
2. **BM25 + 提取是更中立的证据**：仅用关键词检索再后处理，P@8 已达 0.964、延迟 2 ms，说明搭配问题的答案本身较强地暴露在菜谱文本里。
3. **图谱多跳路径并不是准确率最高的方案（0.875）**。它每条路径只落在一个具体食材上，去重后候选数受限；同时它返回的是"路径"而非"频次排序的搭配列表"。
4. **多跳路径的价值不在准确率，而在可解释性**：它能输出 `鸡腿 → 黄焖鸡 → 土豆 → 蔬菜` 这样的完整链路，每条结论可回溯到具体图谱节点，这是向量检索和 BM25 给不出的。
5. **向量检索在搭配任务上最弱（0.867）**，与它擅长语义相似、不擅长聚合共现事实的特性一致。

## 对方案表述的影响

- 可以主张："图谱方案在搭配问答上优于纯向量检索（1.000 vs 0.867）"
- 但**不应主张**"多跳推理提升了搭配准确率"——数据不支持，多跳的定位是提供可追溯的推理路径
- 若要强调多跳价值，应使用"可解释路径覆盖率"这类指标，而非检索精度

## 局限

- 查询规模为 8 个主食材，属于方向性验证。
- 蔬菜分类沿用图谱构建时的 `classify_ingredient`，与被测系统的数据层同源。
