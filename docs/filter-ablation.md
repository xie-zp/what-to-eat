# 元数据过滤增益实验

对比"仅语义检索"与"语义检索 + 元数据硬过滤"在带约束查询上的表现。

## 实验设计

- **查询集**：12 条带明确元数据条件的问法（分类 + 时间 / 难度 / 菜系）
- **标准答案**：独立按菜谱字段筛选，不调用检索代码
- **指标**：约束满足率 = 返回结果中满足全部条件的比例
- **复现**：`python scripts/evaluate_filters.py`

## 实验结果

| 配置 | 约束满足率 | 平均合规条数 | 平均延迟 |
|---|---:|---:|---:|
| 仅语义检索 | 0.600 | 3.00 / 5 | 338 ms |
| 语义检索 + 元数据过滤 | **0.867** | **4.17 / 5** | 283 ms |

## 结论

1. **元数据过滤把约束满足率从 0.600 提升到 0.867（+44%）**。仅靠语义相似度，返回结果中约 40% 不满足"素菜""30 分钟内""难度 ≤2"这类硬条件。
2. **过滤同时降低了延迟**（338 ms → 283 ms）：条件先于融合生效，候选集缩小后排序开销随之下降。
3. 这说明**语义检索擅长相关性、不擅长精确约束**，两类能力必须分开实现，不能依赖模型"理解"条件。
