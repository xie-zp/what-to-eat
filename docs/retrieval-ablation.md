# 检索方案消融实验

对比同一批真实问法在不同召回通道组合下的检索质量，用于验证混合检索相对单路检索的实际收益。

## 实验设计

- **查询集**：33 条手写中文问法，覆盖食材检索、分类检索、菜系检索、约束组合、模糊语义五类
- **标准答案**：直接遍历标准化菜谱数据计算（例如"有什么菜可以用西兰花" = 食材列表含西兰花的菜谱），**不调用任何检索代码**，避免用被测系统评判被测系统
- **指标**：Precision@5、Recall@5 与命中率（至少命中一条标准答案的查询占比）
- **复现**：`python scripts/evaluate_retrieval.py`

## 实验结果

| 召回配置 | Precision@5 | Recall@5 | 命中率 | 平均延迟 |
|---|---:|---:|---:|---:|
| 纯 BM25 | 0.485 | 0.253 | 78.8% | 0 ms |
| 纯向量 | 0.588 | 0.330 | 78.8% | 324 ms |
| 纯图谱 | 0.500 | 0.214 | 72.7% | 7 ms |
| 向量 + BM25 | 0.752 | 0.366 | 93.9% | 326 ms |
| 五路混合（本方案） | **0.776** | **0.386** | **93.9%** | 315 ms |

## 结论

1. **精准率显著优于单路**：相比纯 BM25（0.485）提升 60%，相比纯向量（0.588）提升 32%，相比纯图谱（0.500）提升 55%。
2. **召回率同步提升**：Recall@5 由纯 BM25 的 0.253 提升至 0.386（**+53%**）。
3. **命中率从 78.8% 提升到 93.9%**（+15.1 个百分点），说明多通道能兜住单路漏召回的长尾查询。
4. **向量与 BM25 是主要贡献者**：两路组合已达 0.752，说明语义召回与关键词召回互补性最强。
5. **图谱/实体/主题通道增量有限但为正**：从 0.752 提升到 0.776（+3.2%），主要覆盖分类与菜系类结构化查询；单看延迟，图谱通道最快（7 ms），因为它是精确匹配而非向量计算。

## 局限

- 查询集规模为 33 条，属于小型回归集，用于验证方案方向而非宣称绝对精度。
- **Recall@5 的绝对值偏低**（0.386）是任务特性导致的：部分查询的标准答案有几十条（如"用鸡蛋能做什么"），而 Top-5 最多只能覆盖 5 条，因此该指标被答案集大小稀释；跨配置比较时相对变化仍然有效。
- 当前指标只衡量"检索到正确菜谱"，未覆盖"关系型问答"（如"鸡肉配什么蔬菜"）的质量，这类问题由图谱多跳路径单独评测。
- 延迟包含 BGE 向量编码开销，因而向量相关配置普遍在 270 ms 左右。
