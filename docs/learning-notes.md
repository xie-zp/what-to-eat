# 学习笔记

## 为什么需要工具注册表

Agent 不应该直接调用 Neo4j、Milvus 或任意 Python 函数。注册表将编排逻辑和工具执行分离，让工具 Schema 可以被模型识别，也让每个工具能够单独测试。

## 为什么校验必须确定

过敏原和最大烹饪时间是硬规则，不能只依赖 LLM 判断。Agent 在生成最终回答前，必须通过代码执行校验。

## 为什么第一阶段不接 LLM

先把控制循环、状态模型、工具契约和测试做正确，再引入模型的不确定性。确定性骨架跑通后，模型只负责适合它处理的决策。

## 为什么使用 LangGraph

LangGraph 用状态图表达 Agent 的节点和转移，适合处理循环、分支、重试、中断恢复和人工确认。它负责编排，不负责替代工具中的确定性业务逻辑。
